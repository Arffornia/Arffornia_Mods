# Crafter

The <ItemLink id="arffornia:crafter_block" optional /> turns items into other items using energy. Its recipes are unlocked by milestones: a recipe you have not unlocked yet does not run.

## Running it

| | |
|---|---|
| Input slots | 9 |
| Output slots | 2 |
| Energy buffer | 12,000 FE |

1. Select a recipe you have unlocked. The machine shows its time and energy cost.
2. Put the ingredients in the input slots.
3. Feed it energy. Each side can be set to input, output or off.
4. Take the result from the output slots.

## Unlocking recipes

Recipes unlock by completing milestones at the Space Elevator. The progression viewer shows which milestone unlocks what.
