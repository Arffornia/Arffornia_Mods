# Bloc de fabrication

Le <ItemLink id="arffornia:crafter_block" optional /> transforme des objets en d'autres objets grâce à l'énergie. Ses recettes se débloquent avec les jalons : une recette non débloquée ne se lance pas.

## Recette

<RecipeFor id="arffornia:crafter_block" />

## Utilisation

| | |
|---|---|
| Emplacements d'entrée | 9 |
| Emplacements de sortie | 2 |
| Tampon d'énergie | 12 000 FE |

1. Sélectionnez une recette débloquée. La machine affiche sa durée et son coût en énergie.
2. Placez les ingrédients dans les emplacements d'entrée.
3. Alimentez-la en énergie. Chaque face peut être réglée sur entrée, sortie ou désactivée.
4. Récupérez le résultat dans les emplacements de sortie.

## Débloquer des recettes

Les recettes se débloquent en terminant des jalons à l'Ascenseur spatial. Le visualiseur de progression montre ce que chaque jalon débloque.
